딜메이트는 여러 매물의 정보와 판매자 답변을 한곳에 모아, 무엇이 확인됐고 무엇을 더 물어봐야 하는지 정리해 주는 서비스를 구상하고 있습니다.

아직 이용할 수 있는 서비스는 없습니다. 이 페이지는 준비 중인 서비스의 방향을 소개합니다.

고객의 문제

좋은 매물을 찾은 뒤에도
할 일이 많습니다

1

여러 매물을 오가며 비교해야 해요

가격, 상태, 구성품, 배송비가 판매글마다 다르게 적혀 있어 같은 기준으로 맞춰 보기 어렵습니다.

2

무엇을 물어봐야 할지 막막해요

게시글에 없는 하자, 사용 기간, 실측, 추가 사진처럼 꼭 확인할 내용을 빠뜨리기 쉽습니다. 문의와 가격 제안이 부담스러운 초보자라면 더 그렇습니다.

3

판매자 답변이 흩어져요

여러 판매자와 대화하다 보면 어떤 내용을 확인했고 무엇이 남았는지 다시 정리하게 됩니다.

해결 방식

흩어진 정보를
하나의 구매 작업으로

딜메이트는 검색이나 문장 작성만이 아니라, 여러 매물과 판매자 답변을 쌓아 가며 다음에 할 일을 정리하는 데 집중합니다.

  • 같은 기준으로 비교

    내가 찾은 매물 정보를 붙여 넣으면 가격·상태·거래 조건을 나란히 놓고 내 조건에 맞는지 표시합니다.

  • 확인된 것과 미확인을 구분

    항목마다 ‘게시글 기재 / 판매자 답변 / 미확인’으로 나눕니다. 답하지 않은 내용을 문제없다고 넘겨짚지 않습니다.

  • 다음 질문과 문안 준비

    빠진 내용을 묻는 질문과, 내가 정한 가격 범위 안의 협상 문안을 초안으로 준비합니다.

  • 총구매비용과 남은 확인 사항

    배송비 등 추가 비용을 더해 보고, 아직 모르는 금액은 따로 표시합니다.

구상 원칙

  • 최종 구매 확정과 결제는 구매자가 직접 합니다.
  • 판매자에게 보내는 메시지는 구매자가 검토하고 직접 보냅니다.
  • 중고거래 앱의 비밀번호나 인증 정보는 받지 않습니다.

이용 흐름 (구상)

조건 설정부터
결정까지 다섯 단계

  1. 구매 조건 정하기

    원하는 물품, 예산, 지역, 상태, 거래 방식과 목표 가격을 정합니다.

  2. 찾은 매물 비교하기

    중고거래 앱에서 직접 찾은 매물의 글과 사진을 붙여 넣으면, 후보별 차이와 조건 충족 여부를 정리합니다.

  3. 문의 초안 받아 직접 보내기

    판매 여부, 하자, 구성품 등 물어볼 질문을 초안으로 받아 앱에서 직접 보냅니다.

  4. 답변 정리와 후속 질문

    받은 답변을 입력하면 확인된 것과 남은 것을 나누고, 후속 질문이나 가격 제안 문안을 준비합니다.

  5. 내가 직접 결정하기

    매물별 확인 정보, 총구매비용, 남은 확인 사항을 보고 구매 여부를 직접 결정합니다.

새 매물 자동 알림이나 판매자 자동 연락은 중고거래 플랫폼이 공식적으로 허용하는 범위를 확인한 뒤에만 검토합니다.

  1. 지금구매자의 문제와 이용 흐름 정리
  2. 다음 계획중고 노트북 구매 예정자부터 실제 고민을 듣고 필요성 확인
  3. 그 이후확인한 내용을 기능과 이용 조건에 반영

현재 출시된 서비스, 이용 요금, 이용 후기는 없습니다. 기능과 이용 조건은 검증 과정에서 정해집니다.
